# Лесно — локальный лендинг

Одностраничное портфолио концептуального ландшафтного бюро Екатеринбурга. Три сада, философия и этапы работы. Проекты вымышленные, иллюстрации созданы ImageGen; CTA подключён к Telegram @laimick по указанию владельца.

## Открыть

http://127.0.0.1:3000/

Для повторного запуска выполните `Start-Local.ps1` из этой папки. Он запускает статический сервер в фоне, доступный только на вашем компьютере.

## Разработка

- `pnpm dev --host 127.0.0.1` — разработка с автоматическим обновлением.
- `pnpm build` — сборка в `dist/client`.
- `pnpm start` — показ готовой сборки на порту 3000.
- `pnpm exec tsc --noEmit` — проверка TypeScript.

Перед запуском режима разработки остановите статический сервер командой `Stop-Process -Id (Get-Content .local-server.pid)` из этой папки. Не запускайте два сервера одновременно на порту 3000.

Стек: React 19, TypeScript, Vite 8 / Vinext, обычный CSS. Сохранён стандартный scaffold Sites с shadcn. Приложение экспортируется в статический HTML; баз данных и внешних API нет. Все картинки и шрифты доступны локально (системные Georgia и Arial). Для работы готового сайта интернет не нужен.

`app/page.tsx` — содержание, `app/globals.css` — визуальная система и адаптация, `public/images` — WebP-картинки. Образы и текст можно заменить реальными проектами.

На Windows у закреплённой версии CLI Vinext обнаружен аварийный выход после успешного экспорта. `scripts/build.mjs` использует тот же build API и prerender API с естественным завершением процесса; ошибки не подавляются. `pnpm build` завершается с кодом 0.

После refinement выполнен полный визуальный просмотр в браузере на desktop 1440 px и mobile 390 px, дополнительная проверка ширины 320 px, меню и раскрытия проектов. Подтверждены сборка, TypeScript и HTTP-проверки. Lighthouse не запускался. Адаптивные правила, клавиатурный фокус, нативные раскрывающиеся блоки, альтернативные тексты и reduced-motion включены.
